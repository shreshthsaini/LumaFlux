# Data

The training corpus contains 314,396 SDR and HDR pairs curated from 2,092 source videos. It draws on these sources:

- CHUG user-generated HDR, with 856 reference contents.
- LIVE-TMHDR, with 40 references and 120 expert-graded SDR clips.
- HDRTV1K, with 1,235 native training pairs.
- The Netflix Open Content *Sol Levante* HDR10 master, released under CC BY.

SDR inputs are genuine expert grades when available. Other SDR inputs are generated by a frozen degradation chain: eight tone-mapping operators, BT.2020 to BT.709 gamut conversion, then three CRF settings. HDR targets use the 1,000-nit mastering convention. The curation code stores SDR tensors at 8-bit precision and HDR tensors as 16-bit PQ BT.2020.

## Prepare local media

Obtain each source under its own access and license terms. Edit the paths in `configs/data/example.yaml`, then run:

```bash
python scripts/prepare_data.py --spec configs/data/example.yaml
```

The command writes safetensors shards and `data/curated/manifest.jsonl`. Use `--corpus-output` to choose another output directory and `--workers` to set the curation worker count.

For a separate collection of HDR videos, a minimal source entry is:

```yaml
out_dir: data/curated
sources:
  - name: local_hdr
    path: data/raw/local-hdr
    category: pgc
    format: pq2020
    fps: 1
```

Restricted source media are not redistributed. The release represents those sources through curation code, content identifiers, and checksums rather than copied frames.
